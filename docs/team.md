# Hiero Python SDK Team

The team at the Python SDK includes: triage, committer and maintainer members.

The Hiero Python SDK Team is responsible for the development, quality, and long-term maintenance of the Python SDK. The team is organized into three roles, each with increasing levels of responsibility and access.

GitHub IDs and names are provided as listed on GitHub.

## Triage Members

**Triage members** have read but not write access. Their responsibilities include: mentoring new starters, providing a preliminary review of pull requests, creating and labeling issues, and actively contributing code for the benefit of the Python SDK.

### Qualifications

Triage members should demonstrate:

* Familiarity with the Python SDK codebase, contribution workflow, and project conventions.
* Ability to investigate issues, reproduce problems, and communicate findings clearly.
* Consistent, constructive participation in issues and pull requests.
* Ability to provide useful preliminary feedback on pull requests.
* Willingness to help new contributors understand the project and its development workflow.
* Understanding of the team's code quality, testing, and documentation expectations.

## Committer Members

**Committer members** have write access. Their responsibilities include: creating and laddering issues to incrementally train developers, reviewing pull requests to ensure they meet project standards, and actively contributing code for the benefit of the Python SDK.

### Qualifications

Committer members should demonstrate:

* Sustained, high-quality contributions to the Python SDK.
* Ability to independently implement, test, and maintain changes across relevant areas of the codebase.
* Strong understanding of project conventions, testing, CI, and backward-compatibility requirements.
* Ability to perform meaningful code reviews and identify correctness, maintainability, and compatibility concerns.
* Ability to take ownership of issues and follow changes through implementation, testing, review, and completion.
* Willingness to mentor contributors and help develop issues appropriate to different contributor experience levels.
* Demonstrated judgment and reliability when making changes to the repository.

## Maintainer Members

**Maintainer members** have special write access. Their responsibilities include: provide technical leadership for the SDK, provide leadership on the overall health and direction of the project to ensure it satisfies various scaling and stakeholder needs. They also ensure a welcoming and nourishing environment for all developers and community members, laddering issues, reviewing pull requests and actively contributing code for the benefit of the Python SDK.

### Qualifications

Maintainer members should demonstrate:

* Broad and sustained knowledge of the Python SDK and its architecture.
* Ability to provide technical direction across multiple areas of the project.
* Strong understanding of project health, testing, CI, releases, security, and long-term maintenance.
* Ability to evaluate architectural and compatibility implications of proposed changes.
* Consistent, high-quality code review and contributor mentorship.
* Ability to guide contributors and committers through complex technical or project decisions.
* Demonstrated reliability, sound judgment, and commitment to the long-term health of the project.
* Willingness to participate in project-level planning, issue laddering, and maintenance activities.

Role progression is based on demonstrated readiness, sustained contribution, project needs, and agreement from the existing team rather than a fixed contribution count.
